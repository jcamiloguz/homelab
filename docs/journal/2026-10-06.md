## Wi-Fi notes
- Works fine for everything today. Ethernet is still better for a DNS server (lower latency, no drop-outs).
- Prefer the **5 GHz** network: the Pi's Wi-Fi and Bluetooth share one radio, and 2.4 GHz Wi-Fi competes with the Bluetooth link to the Hue lights.
- Turn off Wi-Fi power saving — it causes random SSH/DNS stalls.
- If DNS feels flaky, don't make the Pi the router's DNS yet; use it only via Tailscale.
- **Moving to Ethernet later:** move the DHCP reservation to the Ethernet MAC and turn Wi-Fi off (`sudo nmcli radio wifi off`), then point the router's DNS at the Pi. Tailscale IP and MagicDNS name don't change.

## microSD notes
- SD cards wear out with constant writes (Pi-hole logs, HA database). Fine for now; move to NVMe when it arrives.
- Keep the Docker data in `${DATA_DIR}` so the move to NVMe is a copy, not a rebuild.
- Take an image of the card once everything works (`dd` / Imager backup) — instant rollback.
