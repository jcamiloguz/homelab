# 2026-10-11 · PiHub on Discord, Hub deployed

- PiHub (Hermes) answers on Discord; gateway runs as system service.
- Hub 0.1.0 deployed from GHCR (private image, `docker login ghcr.io` with a read:packages token). Healthy; published with `tailscale serve` on :443 (first request waits for the Let's Encrypt cert).
- Gotcha: `sudo` "worked" from my non-interactive SSH only because the user had just authenticated — Pi OS shares the sudo timestamp across ttys. Passwordless sudo was never configured.
- Gotcha: a ufw `-A ufw-before-output ... -o lo` rule never matches — before.rules accepts all loopback earlier. Use `-I ufw-before-output 1`. Also block the Docker networks (172.16.0.0/12), or the container IP is a bypass.
- `tailscale set --operator=homelab` → serve/up without sudo.
