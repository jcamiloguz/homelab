- Hub 0.3.0 (portfolio: net worth, trii stocks, market data) deployed: backup first (`backup` subcommand), then `HUB_VERSION=0.3.0`. The container reaches the internet for prices and the Colombian exchange rate.
- Switched to `HUB_VERSION=latest` + installed `hub-deploy.timer` (5 min) and `hub-backup.timer` (03:00). Releasing Hub now deploys it.
- `mem_limit` was silently ignored: Pi OS boots with `cgroup_disable=memory`. Added `cgroup_enable=memory` to cmdline.txt, rebooted, recreated Hub → 256 MiB cap now enforced.
- **hermes could still reach Hub** (both loopback and container IP). before.rules still had the first, wrong `-A` rule — the corrected `-I ... 1` rules never made it into the file. Replaced them with a script (drop old lines, insert before the last COMMIT, reload, test). Now both blocked; hermes still reaches the internet; PiHub still on Discord.
- Lesson: verify security changes with a test that is run (and shown), not "it works".
